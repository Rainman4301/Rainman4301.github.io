dbt Layers
Production weather ETL pipeline — six containerised services (PostgreSQL, Airflow, dbt, Superset, Redis, Cloudflare Tunnel) orchestrated by Docker Compose on Azure VM. Data moves through a medallion architecture: staging → silver (deduplication, UTC-to-local TZ conversion) → mart (daily averages, hourly detail, city summaries). A GitHub Actions CI/CD pipeline validates DAGs, runs dbt parse checks, and executes pytest on every branch before deploying via SSH — credentials injected from GitHub Secrets at runtime, never committed to the repo. Published publicly via Cloudflare Tunnel: outbound-only connection means zero open firewall ports, no certificate management, and built-in DDoS protection.
